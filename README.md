# Inventory CLI

javaによる在庫管理CLIアプリケーション

## 開発環境
- Java 21


### CSV保存・読み込み機能

商品情報をCSVファイルに保存し、次回起動時に復元できる。

**保存形式：** `id,name,stockCount`

**保存先：** `data/products.csv`

**操作方法**
- メニュー5：CSVから読み込み
- メニュー6：CSVに保存

**現在の制約**
- 保存・読み込みは手動操作。
  - 自動化は発展課題
- 商品名にカンマ、ダブルクォーテーション、改行は使用できない。
- 読み込み時は現在の商品一覧を置換する。
- 保存時のファイル書き込み失敗に対する完全な保護は未実装。
- 商品IDは1から採番。
