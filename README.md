# Inventory CLI

javaによる在庫管理CLIアプリケーション

## プロジェクト概要

本プロジェクトは、Javaの基礎知識の復習と、オブジェクト指向設計・テスト実装への理解を深めることを目的として開発している、就職活動用のポートフォリオです。

在庫管理を題材としたCLIアプリケーションを段階的に実装することで、Javaの基本構文やコレクション操作に加え、例外処理、ファイル入出力、JUnitによる単体テストなど、実務で使用する基本的な技術の再確認に取り組んでいます。

また、保守性や拡張性を意識し、Service層とRepository層の責務分離、インターフェースを利用した依存関係の整理など、オブジェクト指向設計の実践も進めています。

今後はSpring BootによるWeb API化とPostgreSQLとの連携を予定しており、CLIアプリケーションからWebアプリケーションへ段階的に発展させる方針です。

### 本プロジェクトで重点的に取り組む内容

- **Java基礎**：クラス設計、コレクション、例外処理、ファイル入出力
- **オブジェクト指向設計**：責務の分離、インターフェース、依存性注入（DI）
- **テスト**：JUnit 5による単体テスト・永続化処理の検証
- **データ管理**：CSVによる永続化、データ整合性の検証
- **今後の拡張**：Spring BootによるREST API実装、PostgreSQLとの連携

## 開発環境
- Java 21


### CSV保存・読み込み機能

商品情報をCSVファイルに保存し、次回起動時に復元できる。

**保存形式：** `id,name,stockCount`

**保存先：** `data/products.csv`

**操作方法**
- メニュー5：CSVから読み込み
- メニュー6：CSVに保存

**現在の制約**
- 保存・読み込みは手動操作。
  - 自動化は発展課題
- 商品名にカンマ、ダブルクォーテーション、改行は使用できない。
- 読み込み時は現在の商品一覧を置換する。
- 保存時のファイル書き込み失敗に対する完全な保護は未実装。
- 商品IDは1から採番。
